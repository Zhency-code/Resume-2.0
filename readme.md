# ResumeV2 — Online Resume

A responsive multi-page online resume built with HTML, CSS, and JavaScript. The existing `pages/page1`, `pages/page2`, and `pages/page3` folders are used for About, Skills & Projects, and Contact.

## Run locally
1. Open this folder in Visual Studio Code.
2. Use Live Server, or open `index.html` in a browser.
3. Navigate using the header links.

## Before publishing
Replace the sample email, GitHub, and LinkedIn information in `pages/page3/index.html` and the recipient address in `pages/page3/assets/js/scripts.js`. Review all personal descriptions and project claims.
