# ResumeV2 — Personal Online Resume

## About the Project

ResumeV2 is a personal online resume and portfolio website created to present my personal profile, skills, projects, and other relevant information. It uses a black-and-red visual theme with a clean layout, animations, and interactive elements.

## Features

- Personal homepage and introduction
- Additional pages for portfolio content
- Black-and-red design
- CSS styling and animations
- JavaScript interactions
- Organized project files
- Separate CSS and JavaScript files for individual pages

## Technologies Used

- **HTML5** — Website structure and content
- **CSS3** — Styling, layout, responsiveness, and animations
- **JavaScript** — Interactive features and page behavior

## How to Run

1. Download or clone the project repository.
2. Extract the project folder if it was downloaded as a ZIP file.
3. Open the `ResumeV2` folder.
4. Open `index.html` in a web browser.

For the best results, use a local development server such as the Live Server extension in Visual Studio Code.
